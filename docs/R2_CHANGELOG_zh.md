## 4. 本轮统计性质与结果边界

原模型、原始已发布预测和旧结果不改动。本轮新增的是：固定预测上的跨主干效应差；Frozen额外订单分数恢复及未知标签界限；包含Frozen的日/周时间汇总。原有核心配对区间重新计算核对，不重训模型、不搜索参数。

- Core O2 Expanding−Frozen的Brier与LogLoss在3/7/14日块下均为正区间；Restricted与CatBoost同起点的该比较也保持正区间。
- Core O3 Expanding−Frozen区间仍跨零；不能把初始校准损失全部归为持续更新。
- CatBoost O3 Expanding−Raw点估计较Core更大，即使其单独区间跨零，也不能说损害消失。直接效应差与绝对评分已补齐。
- O2额外可打分Noncancelled订单的Expanding−Frozen Brier界限为[+0.003046,+0.004381]；0/30/60/90日阈值为同一订单集合，不是四份独立证据。
- O3/O4的对应未知标签界限跨零。界限只涉及固定分数下未知二元标签，不覆盖基础模型/特征/校准池重建。
- 校准图的诊断回归联合拟合截距和斜率，截距不是固定斜率的calibration-in-the-large；分箱显示与斜率比较不构成因果解释。
