# Source-code license decision (author action required)

The repository currently has **no software license**, intentionally. A dataset's CC BY-NC-SA or Apache-2.0 metadata does not authorize the publisher to relicence that dataset. GitHub public repositories do not automatically grant arbitrary reuse rights. See https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository.

After checking all authors' and institutions' policies, choose e.g. MIT (permissive), BSD-3-Clause, or Apache-2.0 (patent provisions) for the **reproduction code only**. Add a real `LICENSE` file, with correct holder(s)/year; keep each external dataset under its respective license, acquired by users from the original sources.
